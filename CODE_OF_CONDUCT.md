# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part in the project, in issues,
pull requests, discussions or any other project space, is expected to follow
it.

## Reporting

Report unacceptable behaviour privately to the project maintainer (GitHub user
`owenjacob-dev`). Reports are handled confidentially. The maintainer applies
the enforcement guidelines in section "Enforcement Guidelines" of the
Contributor Covenant.
